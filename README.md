# git-tag-generator

## Descrição

Script para a criação automatizada de tags remota e local para o GitHub.

O código usa como base uma lista para prefixos de projetos destinados à produção e outra para homologação.

## Uso

Após a ativação, infome a versão das tags.
Em seguida, as tags serão registradas localmente e se quer iniciá-las remotamente com um push.
